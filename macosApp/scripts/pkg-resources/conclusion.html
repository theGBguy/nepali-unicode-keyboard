Nepali Unicode Keyboard is installed

  1. Click the input menu in the menu bar and choose Nepali – Romanized or Nepali – Traditional.
  2. Type. Press Globe or Control-Space to switch back to English.
  3. Settings and the Romanized typing guide are in the same menu, under Settings…

If the input sources aren't in the menu, log out and back in, or add them in System Settings → Keyboard → Text Input → Input Sources → Edit → + → Nepali.
