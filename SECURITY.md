# Security and privacy

A keyboard sees everything you type, so security and privacy bugs are the most important ones to report. Examples include text being stored or logged when it shouldn't be, suggestions or the clipboard showing up in password fields, and data leaving the phone.

**Please don't open a public issue for these.** Report them privately through [GitHub's private vulnerability reporting](https://github.com/theGBguy/nepali-unicode-keyboard/security/advisories/new) or by email to nepali.indie.dev@gmail.com.

Include the app version, your phone model and Android version, and steps to reproduce. You'll get a reply within a week. Once a fix is released on Google Play, the report can be made public with credit to you, if you want it.

Only the latest version on Google Play is supported.
